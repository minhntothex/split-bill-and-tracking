# DESIGN.md

## Design Direction

Modern, clean, practical product UI.

Focus on usability and readability over visual experimentation.

The product should feel:

* fast
* lightweight
* mobile-first
* touch-friendly
* financially clear
* production-ready

## Visual Style

Inspired by:

* Linear
* Notion
* Revolut
* Vercel

## Layout

* Prefer compact layouts
* Avoid oversized sections
* Avoid excessive empty space
* Keep important actions visible
* Prefer content-first UI

## Spacing

* Use a consistent spacing system
* Keep mobile spacing comfortable
* Avoid cramped forms
* Avoid excessively large cards

## Typography

* Use strong hierarchy
* Keep text readable
* Avoid tiny text
* Avoid excessive font weights

## Components

* Soft borders
* Minimal shadows
* Clean inputs
* Compact dialogs
* Touch-friendly controls

## Motion

* Use minimal motion only
* Use animation for clarity
* Avoid cinematic transitions
* Avoid decorative motion

## Avoid

* Glassmorphism
* Heavy gradients
* Neon effects
* Floating decorative elements
* Fancy dashboards
* Marketing-style hero sections

## Product UX Priorities

Optimize for:

1. Speed
2. Readability
3. Mobile usability
4. Financial clarity
5. Fast bill entry
6. Easy balance scanning
